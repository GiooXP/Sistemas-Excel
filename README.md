# 📊 Soluções Inteligentes em Excel para Gestão de Negócios

Este repositório reúne projetos e ferramentas desenvolvidas em Excel, focadas em automação de processos, controle financeiro e gestão operacional. O objetivo é demonstrar como a tecnologia pode otimizar a tomada de decisão no ambiente empresarial.

---

## 🍕 Projeto em Destaque: Sistema de Gestão para Pizzaria

Este é um sistema completo de automação comercial desenvolvido para gerenciar as operações de uma pizzaria, integrando vendas e estoque de forma inteligente.

### 🛠️ Funcionalidades Principais:
*   **Abatimento de Estoque Automatizado:** O sistema utiliza lógica avançada para deduzir automaticamente os insumos (farinha, queijo, molho, etc.) a cada venda realizada.
*   **Controle de Vendas:** Registro detalhado de pedidos com interface de fácil navegação.
*   **Gestão Financeira:** Relatórios integrados para acompanhamento de faturamento e fluxo de caixa.
*   **Fórmulas Utilizadas:** Uso extensivo de funções lógicas complexas, validação de dados e funções de busca avançada (como `PROCX` / `XLOOKUP`).

---

## 🛠️ Competências Técnicas Demonstradas

*   **Lógica de Programação em Planilhas:** Estruturação de dados para evitar redundância.
*   **Automação:** Redução de erros humanos através de cálculos automatizados.
*   **Dashboards e Relatórios:** Transformação de dados brutos em informações visuais para gestão.
*   **Gestão de Estoque (SLA e Aging):** Aplicação de conceitos de logística e prazos no controle de materiais.

---

## 📂 Como utilizar os arquivos

1.  Faça o download do arquivo `.xlsx` desejado.
2.  Certifique-se de habilitar as macros (caso o projeto contenha VBA).
3.  Consulte as abas de "Instruções" dentro de cada planilha para entender o fluxo de dados.
